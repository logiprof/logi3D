=== Logi3D ===

Ajouter une animation
1. Menu « Logi3D » dans l'administration WordPress.
2. « Ajouter ou remplacer une animation » : choisis le fichier .html, donne un identifiant (ex. gestion-des-stocks).
3. Copie le code court affiché, par ex. [logi3d_gestion_des_stocks], dans un bloc « Code court ».

Mettre à jour une animation
Téléverse le nouveau fichier avec le même identifiant. Les codes courts déjà placés affichent la nouvelle version.

Options
[logi3d id="surfaces-volumes" hauteur="1200"]        hauteur de départ en pixels

Les animations ajoutées sont stockées dans wp-content/uploads/logi3d/
et sont conservées quand l'extension est mise à jour.

Logo en surcouche
Menu « Logi3D » → « Logo en surcouche » : choisis le logo dans la médiathèque,
sa position, sa largeur et son opacité. Il s'affiche sur toutes les animations.
Pour le cacher sur une seule : [logi3d id="surfaces-volumes" logo="non"]

Largeur
L'animation prend toujours la largeur du contenu de la page ou de la leçon Sensei, comme le texte.

Mises à jour
Logi3D se met à jour tout seul depuis https://github.com/logiprof/logi3d
(page Extensions → lien « Rechercher une mise à jour » pour vérifier tout de suite).
